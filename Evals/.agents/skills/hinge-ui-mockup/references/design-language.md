# Hinge design language

Use the four bundled screenshots as visual references, not as an official Hinge specification.

## Visual system

- Design a native-looking iOS screen in a narrow portrait layout.
- Use warm white or pale gray backgrounds, near-black text, and generous spacing.
- Use a clean sans serif for most text. Reserve an editorial serif for an occasional expressive heading.
- Build hierarchy with type size and weight rather than many colors.
- Use deep plum for the main action. Use dark teal only when it serves a distinct context; do not make both colors compete.
- Use wide pill buttons, rounded white cards or modals, thin dividers, and simple black line icons.
- Keep one dominant section and one primary action on the screen.
- Illustrations may use black outlines, light texture, and muted pastel fills.
- Avoid gradients, glass effects, neon, 3D renders, dense dashboards, and decorative AI sparkles.

## Voice

- Write warm, direct, encouraging copy.
- Explain the benefit in plain language and keep interface text short.
- Describe AI as helpful guidance, not an authority or judge.
- Emphasize privacy, consent, and the user's ability to ignore a recommendation.

## AI profile reviewer

Make the feature feel like a thoughtful profile coach. Depending on the requested screen, show only the elements needed from this set:

- what the reviewer will examine
- consent before analysis
- a simple overall result
- a few prioritized recommendations with clear reasons
- a direct action such as improving a photo or rewriting an answer
- a way to dismiss the advice or keep the current profile

Never rate attractiveness or rank the user against other people.
