# Discovery screen

A local React and Vite recreation of the supplied Glovo discovery screen from Hatch Conference — MCP, node 5:24131. The user wants the complete screen reproduced with exact visual fidelity. The supplied Figma screen is the visual authority; its text and layout are preserved.

The app is a frontend demonstration. Search, browsing carousels, saved restaurants, address editing, product details, and a local cart work without a backend. No orders or payments are submitted.
