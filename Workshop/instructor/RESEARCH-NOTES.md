# Preparation research and decisions

Checked during workshop preparation on 8 September 2026.

- **Skill packaging and invocation:** the current [official OpenAI skill documentation](https://learn.chatgpt.com/docs/build-skills) supports a named `SKILL.md` with a description, linked supporting resources, explicit selection, and optional invocation policy. The lesson teaches the difference between a useful trigger and an execution procedure. Host-specific settings are optional demonstrations, not prerequisites shared by every coding agent.
- **Output design:** the supplied Figma issue frame was inspected in the native app and exported. Its dark header and paired Current/Expected evidence columns informed the actual version 3 HTML asset. Its sample brand and issue were not treated as discovery-app findings.
- **Evidence boundaries:** the existing app and its Git history contain implementation clues and an answer map. A prompt cannot remove an unrestricted agent's filesystem access. The participant distribution and fresh-task procedure therefore separate authoring from auditing, and the guide distinguishes guided practice from technically isolated evaluation.
- **Capture conditions:** actual forward testing exposed a fixed-navigation mismatch between a long design export and a browser screenshot. Matching image regions removed that artifact from the retest. This observation is included in the reference guide and teacher preparation.
- **Teaching decisions:** the 165-minute sequence, pair work, prediction prompts, and gradual reference release are facilitation choices for this workshop. They have been reviewed for coherence and artifact completeness; audience engagement has not yet been measured in a live classroom.

This package does not claim that a particular paid plan, plugin catalog, cheapest model, Figma quota, or UI control will remain unchanged until the event. Rehearse the available account/tool path and use the included offline inputs when necessary.
