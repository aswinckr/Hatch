# Presentation

- **Hatch-workshop-instructor.pptx:** editable 51-slide deck with private teacher notes.
- **Hatch-workshop-participant.pptx:** the same teaching slides with presenter notes removed.
- **Hatch-workshop-participant.pdf:** portable slide handout.
- [Teacher guide](../instructor/TEACHER-GUIDE.md) and [slide notes](../instructor/SLIDE-NOTES.md): readable instructions and prompts.

The deck preserves the supplied white, serif-led style and original illustrations. About Me and My Projects remain TODO placeholders for Aswin. The original Google Slides file is retained at [Hatch 2027](https://docs.google.com/presentation/d/1BbLX-yzhnm64zwGhqZCiI_G9zxLpsJ2yy-KKys0ke0E/edit).

The revised deliverables are the files in this folder. The original Google Slides document has not been overwritten. Use the PPTX as the editable workshop master or import a copy into your presentation application if desired.

The deck uses Instrument Serif and Arial. The open-source Instrument Serif font and its license are in `fonts`; install it before editing on a machine where it is unavailable. The PDF preserves the rendered appearance without requiring font installation. [Font source](https://github.com/google/fonts/tree/main/ofl/instrumentserif).

Presenter notes are excluded from the participant PPTX and PDF, but the teacher guide is intentionally readable in this repository. “Private” means presenter material for the session, not a claim that GitHub readers cannot access it. Seeded answers and complete instructor app material are kept in the encrypted instructor package.
