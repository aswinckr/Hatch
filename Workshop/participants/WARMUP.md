# Earlier tool exercises

These exercises precede the 165-minute design QA section. They use a separate [starter page](../exercise/warmup.html), so changes here do not affect the QA baseline. Read the [product brief](../exercise/WARMUP-PRODUCT.md). Download the file into your own working folder and open it in a browser. The teacher can use the completed starter demo from the instructor pack as a fallback.

## An existing design skill

Install the Impeccable skill through your host's available plugin or skill interface. Confirm it is available before beginning; do not assume every account has the same marketplace controls.

```text
Use the installed Impeccable design skill to improve this starter page.
Keep its existing purpose and content. First tell me the main design decision
you would make, then implement it in this working copy. Show me the result
in the browser and explain one tradeoff.
```

Save a before and after screenshot. Tell a partner which decision improved the page and why.

## A persona review

```text
Create a focused reviewer for this page using the target audience described
in the product brief. Review what a first-time visitor can understand and do.
For usability, comprehension, coverage, and simplicity, provide one specific
observation and its visible evidence. If you use scores, explain the rubric
and label the review as a simulated perspective, not real user research.
Do not edit the page during the review.
```

Use your host's subagent feature if available. Otherwise perform the review in a separate fresh task. Do not confuse a simulated persona with actual participant research.

## A tool connection

With Figma access available, ask the connected tool to create a copy of your warmup page in an exercise file. Use a new exercise file rather than editing someone else's source design.

```text
Use the connected Figma tool to create an editable representation of my
warmup page in the exercise file I provide. Preserve the visible content.
Tell me what can be represented faithfully and what needs manual review.
```

If write access is unavailable, demonstrate obtaining a screenshot from Figma and discuss what the tool made accessible. Record the fallback rather than claiming a write succeeded.

## A concrete goal

```text
Improve this warmup page until a first-time visitor can identify its purpose,
find its main action, and complete the intended navigation without a dead end.
Use the review evidence to choose changes. After each change, check the same
criteria. Stop after two improvement passes and report remaining issues.
```

Use the host's goal feature when available. Otherwise execute the same bounded sequence manually. A reviewer score is a discussion aid, not the only stopping rule.

## A plugin workflow

Use an installed brainstorming skill, such as the workshop's Superpowers example, to consider one useful animation.

```text
Brainstorm one motion treatment for this page that helps someone understand
an action or change of state. Explain its purpose and its reduced-motion
alternative. After I choose the idea, implement it in this working copy.
```

Share the effect and explain what it communicates. Keep a still version available. Then move to the QA exercise with a fresh task and its separate inputs.
